# Incidentes (R2, opcional)

Informes `INC-<fecha>-<id>.md` de triage de solo lectura.

- Síntoma, evidencia enmascarada, primer error, versión desplegada y último RUN verde.
- Hasta 3 hipótesis ordenadas, cada una con su evidencia.
- Caso de regresión sugerido para que S2 lo formalice.
- No modifica código, no reinicia servicios y no afirma la causa como hecho.
- Si no hay evidencia, se dice.

Skill: `formato-de-hallazgos`.
