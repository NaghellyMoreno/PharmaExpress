# TC-008. El tercer intento fallido inactiva el código y deriva a la ruta alternativa

Origen: SPEC-001/AC-011
REQ del MVP: SPEC-001/RF-005
Técnica: Valores límite
Oráculo: definitivo
Origen del oráculo: APROBADO
@supuesto: no

## Precondiciones
- Código de un solo uso vigente (emitido hace menos de 10 minutos), estado «Código Emitido».

## Pasos
1. Intento 3 con código incorrecto: el sistema inactiva el código actual.
2. El sistema muestra de inmediato la ruta alternativa: solicitar nuevo código, orientación para actualizar datos en la EPS o atención presencial.
3. Se intenta el ingreso con el código ya inactivo.

## Datos de entrada (sintéticos)
- Código: `548920`.

## Resultado esperado
- Tras el 3.º intento fallido: el código queda inactivo y se deriva a la ruta alternativa.
- Intento posterior sobre el código inactivo: rechazado.

## Casos negativos y de límite incluidos
- Límites: el 3.º intento fallido es el último permitido; el intento sobre código inactivo siempre es rechazado.
