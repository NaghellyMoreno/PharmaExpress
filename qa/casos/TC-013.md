# TC-013. Solicitar un nuevo código anula el anterior; la solicitud simultánea deja solo el último vigente

Origen: SPEC-001/AC-003
REQ del MVP: SPEC-001/RF-005
Técnica: Transición de estados + concurrencia
Oráculo: definitivo
Origen del oráculo: APROBADO
@supuesto: no

## Precondiciones
- Usuario con código vigente (emitido hace menos de 10 minutos), estado «Código Emitido».

## Pasos
1. El usuario solicita un nuevo código mientras el actual sigue vigente.
2. El sistema anula de inmediato el código anterior y genera/emite un nuevo (reinicia contador de intentos y tiempo de 10 minutos).
3. (Concurrencia) Dos solicitudes simultáneas de nuevo código: el sistema debe dejar solo el último emitido como vigente.

## Datos de entrada (sintéticos)
- Código previo: `548920`. Nuevo código: `741203`.

## Resultado esperado
- El código anterior queda anulado y solo el nuevo es válido.
- En la variante simultánea, el último código emitido es el único aceptable.

## Casos negativos y de límite incluidos
- Concurrencia: solicitudes simultáneas de nuevo código (CL-001); máximo 1 código vigente.
