# TC-006. El código emitido a las 10:00:00 acepta a las 10:09:59 y rechaza a las 10:10:00 con la ruta alternativa

Origen: SPEC-001/AC-009
REQ del MVP: SPEC-001/RF-005
Técnica: Valores límite
Oráculo: definitivo
Origen del oráculo: APROBADO
@supuesto: no

## Precondiciones
- Código de un solo uso emitido a las 10:00:00 (sintético), estado «Código Emitido».

## Pasos
1. El usuario ingresa el código correcto a las 10:09:59 → el sistema valida la identidad.
2. El usuario ingresa el código correcto a las 10:10:00 → el sistema lo rechaza por expirado.

## Datos de entrada (sintéticos)
- Código: `548920`.
- Momento de emisión: 10:00:00. Momentos de ingreso: 10:09:59 y 10:10:00.

## Resultado esperado
- A las 10:09:59: el código correcto se valida y la identidad queda verificada.
- A las 10:10:00 o posterior (incluido el límite): el código se rechaza por expirado y se muestra la ruta alternativa (solicitar nuevo código, orientación EPS, atención presencial).

## Casos negativos y de límite incluidos
- Límites: 10:09:59 (válido) vs 10:10:00 (rechazado, límite superior de la vigencia); transición en el límite.
- Límite inferior: código emitido a las 09:59:00, ingresado a las 10:00:00 (10m exactos) → rechazado por expirado (CL-003).
