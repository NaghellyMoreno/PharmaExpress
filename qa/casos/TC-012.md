# TC-012. El fallo en el envío de SMS o correo informa y ofrece reintentar o atención presencial

Origen: SPEC-001/AC-013
REQ del MVP: SPEC-001/RF-011
Técnica: GWT
Oráculo: definitivo
Origen del oráculo: CONFIRMADO
@supuesto: no

## Precondiciones
- Código de un solo uso emitido; fallo simulado en el servicio externo de SMS o correo.

## Pasos
1. El sistema detecta la falla de entrega del código.
2. El sistema informa la novedad al usuario.

## Datos de entrada (sintéticos)
- Canal afectado: SMS y/o correo (según existencia registrada).

## Resultado esperado
- El sistema informa la falla y ofrece las opciones: reintentar el envío del código o acudir a la atención presencial.

## Casos negativos y de límite incluidos
- Flujo alternativo: E5 (fallo en el servicio externo de envío de SMS o correo).
