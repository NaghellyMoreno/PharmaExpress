# TC-005. Se exige autorización separada de datos de salud antes de cargar documentos

Origen: SPEC-001/AC-005
REQ del MVP: SPEC-001/RF-007
Técnica: GWT
Oráculo: definitivo
Origen del oráculo: CONFIRMADO
@supuesto: no

## Precondiciones
- Titular con identidad verificada y disposición de cargar fórmula o historia clínica.

## Pasos
1. El usuario se dispone a cargar el documento.
2. El sistema solicita la autorización separada para datos de salud.
3. El usuario acepta o no acepta.

## Datos de entrada (sintéticos)
- Autorización: separada de la aceptación general del tratamiento de datos.

## Resultado esperado
- Si acepta: el sistema continúa con la carga del documento.
- Si no acepta: el sistema informa la atención presencial y no pide ni guarda datos de salud.

## Casos negativos y de límite incluidos
- Negativo: sin autorización separada no se solicitan datos de salud.
