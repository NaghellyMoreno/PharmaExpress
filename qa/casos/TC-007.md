# TC-007. Los intentos fallidos de 1.º y 2.º permiten reintento indicando los intentos restantes

Origen: SPEC-001/AC-010
REQ del MVP: SPEC-001/RF-005
Técnica: Valores límite
Oráculo: definitivo
Origen del oráculo: CONFIRMADO
@supuesto: no

## Precondiciones
- Código de un solo uso vigente (emitido hace menos de 10 minutos), estado «Código Emitido».

## Pasos
1. Intento 1 con código incorrecto: el sistema informa el error y muestra 2 intentos restantes; permite reintento.
2. Intento 2 con código incorrecto: el sistema informa el error y muestra 1 intento restante; permite reintento.

## Datos de entrada (sintéticos)
- Código: `548920`.
- Resultados de intento: fallido, fallido.

## Resultado esperado
- En intento 1: error, intentos restantes = 2, reintento permitido con el mismo código.
- En intento 2: error, intentos restantes = 1, reintento permitido con el mismo código.

## Casos negativos y de límite incluidos
- Límites: el reintento procede en los intentos 1 y 2; el 3.º intento fallido inactiva el código (TC-008).
